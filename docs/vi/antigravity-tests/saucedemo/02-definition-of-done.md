# Tiêu chí chung (Definition of Done)

- Mỗi TC: kết luận **Pass**, **Fail**, hoặc **Cần xác nhận thủ công** (khi agent không chắc hoặc UI khác mô tả).
- **Fail:** phải có **bước tái hiện** cụ thể; nếu công cụ hỗ trợ thì kèm **screenshot** hoặc mô tả trạng thái UI.
- Kết quả agent **không** thay thế sign-off production — đây là smoke / luyện tập có kiểm soát.
