Task Management System Overview

This project is a small backend for practicing common tester workflows:

  • reading API documentation
  • sending requests through Swagger, Postman, or curl
  • validating authorization behavior
  • checking persisted data directly in PostgreSQL
  • comparing API responses with database state

Scope

The system contains three main modules:

  • Authentication
  • Project management
  • Task management

Suggested workflow

  1. Read ./api-spec.html to understand the public contract.
  2. Review ./jira-tickets.html for requirement context.
  3. Exercise endpoints through Swagger UI or Postman.
  4. Verify stored data with SQL.

Available references

  • API specification: ./api-spec.html
  • Jira-style requirements: ./jira-tickets.html
  • Swagger UI: http://localhost:3000/api-docs
